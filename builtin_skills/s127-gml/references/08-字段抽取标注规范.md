# S-127 字段抽取标注规范

## 说明

- 抽取级别：
  - 必抽：创建该要素后必须抽取。
  - 条件抽：原文出现相关信息才抽取，未出现不填。
  - 按需：可选字段，仅在能提高信息可用性时填写。
  - 慎用/不抽：当前生产规则明确不表达，或一般不建议创建。
- 公共字段适用于所有对应要素；各要素章节只重点列出特有字段和需要特别说明的公共字段。

---

## 公共字段

### FixedDateRange（有效时间）

- 抽取级别：条件抽
- `dateStart`（条件抽）：生效开始日期，格式 `YYYYMMDD`。
- `dateEnd`（条件抽）：失效日期，格式 `YYYYMMDD`；无失效时间不填。

### FeatureName（要素名称）

- 抽取级别：必抽
- `Language`（必抽）：名称语言，使用 ISO 639-3；英文 `eng`，中文 `zho`。
- `Name`（必抽）：要素名称，非枚举属性先英文后中文。
- `displayName`（条件抽）：是否显示名称；`Applicability` 中英文均不选，其他要素中文通常选 `true`。

### SourceIndication（资料来源）

- 抽取级别：条件抽
- `CategoryOfAuthority`（条件抽）：发文机构类型；直属海事局及以上填 `maritime`。
  - 枚举值：customs(1); border control(2); police(3); port(4); immigration(5); health(6); coast guard(7); agricultural(8); military(9); private company(10); maritime police(11); environmental(12); fishery(13); finance(14); maritime(15)。
- `CountryName`（条件抽）：国家名称；中国填 `China`。
- `ReportedDate`（条件抽）：文件来源日期，优先级为印发时间、签发时间、网络发布时间。
- `Source`（条件抽）：优先填文件编号，无编号填文件名称；中英文同时填入。
- `SourceType`（条件抽）：直属海事局及以上填 `law or regulation`；地方海事局及以下填 `official publication`。
  - 枚举值：law or regulation(1); official publication(2); mariner report, confirmed(7); mariner report, not confirmed(8); industry publications and reports(9); remotely sensed images(10); photographs(11); products issued by HO services(12); news media(13); traffic data(14)。
- `FeatureName`（条件抽）：发文机构名称。
  - `Language`：机构名称语言，`eng` 或 `zho`。
  - `Name`：机构名称，可使用 CHINA MSA、VTS Center 等缩略词。

### TextContent（文本内容）

- 抽取级别：条件抽
- `categoryOfText`（条件抽）：文本有内容时必填。
  - 枚举值：abstract or summary(1); extract(2); full text(3)。
- `Information`（条件抽）：文本信息。
  - `Headline`：文本标题或分类名称。
  - `Language`：文本语言，`eng` 或 `zho`。
  - `Text`：文本正文，不超过 300 字符；超长时拆成多个 `Information`。
  - `fileLocator`（按需）：外部文本片段定位。
  - `fileReference`（按需）：外部文本文件名。
- `onlineResource`（按需）：在线资源。
  - `Linkage`：在线资源地址。
  - `Protocol`：访问协议。
  - `ApplicationProfile`：应用配置文件名称。
  - `NameOfResource`：资源名称。
  - `OnlineResourceDescription`：资源用途说明。
  - `OnlineFunction`：资源功能。
    - 枚举值：download(1); information(2); offline access(3); order(4); search(5); complete metadata(6); browse graphic(7); upload(8); email service(9); browsing(10); file access(11)。
  - `ProtocolRequest`：访问资源的请求内容。
- `SourceIndication`（按需）：附加来源，结构同公共字段 `SourceIndication`。

### Geometry（几何）

- 抽取级别：必抽，适用于所有地理要素。
- 作用：表达要素的水域、线、点或区域范围。
- 说明：范围来自坐标描述、ENC 引用或文本勾绘；JSON 中未展开子字段。

### graphic（图形/方位信息）

- 抽取级别：按需
- 适用对象：`NauticalInformation`、`Regulations`、`Restrictions`、`Recommendations`。
- `pictorialRepresentation`：图片表示。
  - `pictureCaption`：图片用途简短说明。
  - `sourceDate`：图片来源日期。
  - `pictureInformation`：图片版权、制作者等信用信息。
- `bearingInformation`：方位信息。
  - `cardinalDirection`：方位方向。
    - 枚举值：N(1); NNE(2); NE(3); ENE(4); E(5); ESE(6); SE(7); SSE(8); S(9); SSW(10); SW(11); WSW(12); W(13); WNW(14); NW(15); NNW(16)。
  - `Distance`：两点间距离。
  - `Orientation`：方位角。
  - `sectorBearing`：扇形方位。
  - `Information`：方位信息补充文本，结构同 `TextContent.Information`。

### rxnCode（规则结构化编码）

- 抽取级别：条件抽
- 适用对象：`NauticalInformation`、`Regulations`、`Restrictions`、`Recommendations`。
- `categoryOfRxN`：规则主题分类，如航行、通信、环境保护等。
  - 枚举值：navigation(1); communication(2); environmental protection(3); wildlife protection(4); security(5); customs(6); cargo operation(7); refuge(8); health(9); natural resources or exploitation(10); port(11); finance(12); agriculture(13)。
- `actionOrActivity`：约束的具体船舶活动，如引航、靠泊、锚泊等。
  - 枚举值：navigating with a pilot(1); entering port(2); leaving port(3); berthing(4); slipping(5); anchoring(6); weighing anchor(7); transiting(8); overtaking(9); reporting(10); working cargo(11); landing(12); diving(13); fishing(14); discharging overboard(15); passing(16)。
- `Headline`：将规则概括为分类名称。

## 信息要素字段

### NauticalInformation / Regulations / Restrictions / Recommendations

- 作用：表达航海信息、法规、限制或推荐性内容。
- `categoryOfAuthority`（条件抽）：发文机构类型。
  - 枚举值：customs(1); border control(2); police(3); port(4); immigration(5); health(6); coast guard(7); agricultural(8); military(9); private company(10); maritime police(11); environmental(12); fishery(13); finance(14); maritime(15)。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`、`TextContent`、`graphic`、`rxnCode`。
- 说明：`Regulations` 表达直属海事局及以上机构的信息，`Restrictions` 表达地方海事局及同级机构的信息。

### Authority（机构）

- 作用：表达主管机关；所有地理要素关联唯一 Authority。
- `categoryOfAuthority`（条件抽）：机构类型。
  - 枚举值：customs(1); border control(2); police(3); port(4); immigration(5); health(6); coast guard(7); agricultural(8); military(9); private company(10); maritime police(11); environmental(12); fishery(13); finance(14); maritime(15)。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`、`TextContent`。
- 说明：`SourceIndication` 在可复用机构要素中通常不填。

### ShipReport（船舶报告）

- 作用：表达报告类型、报告时间、IMO 格式和报告要求。
- `categoryOfShipReport`（条件抽）：报告类型。
  - 枚举值：sailing plan(1); position report(2); deviation report(3); final report(4); dangerous goods report(5); harmful substances report(6); marine pollutants report(7); any other report(8)。
- `IMOFormatForReporting`（条件抽）：是否必须使用 IMO 标准报告格式。
- `NoticeTime`（条件抽）：提前报告时间。
  - `noticeTimeHours`：提前报告的小时数。
  - `noticeTimeText`：对提前时间的补充说明，如"3 working days"、"On departure from last port"。
  - `Operation`（按需）：时间计算方式，JSON 未给出枚举，按 S-127 定义核对。
    - 枚举值：largest value(1); smallest value(2)。
- `TextContent`（条件抽）：报告格式、内容、方式等无法用专用字段表达的文本。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`。

### Applicability（适用船舶）

- 作用：表达适用船舶类型和船舶参数。
- `inBallast`（条件抽）：是否限定压载船舶。
- `categoryOfCargo`（条件抽）：货物类型。
  - 枚举值：bulk(1); container(2); general(3); liquid(4); passenger(5); livestock(6); dangerous or hazardous(7); heavy lift(8); ballast(9)。
- `categoryOfDangerousOrHazardousCargo`（条件抽）：危险品或有害物质类别。
  - 枚举值：IMDG Code Class 1 Div. 1.1(1); IMDG Code Class 1 Div. 1.2(2); IMDG Code Class 1 Div. 1.3(3); IMDG Code Class 1 Div. 1.4(4); IMDG Code Class 1 Div. 1.5(5); IMDG Code Class 1 Div. 1.6(6); IMDG Code Class 2 Div. 2.1(7); IMDG Code Class 2 Div. 2.2(8); IMDG Code Class 2 Div. 2.3(9); IMDG Code Class 3(10); IMDG Code Class 4 Div. 4.1(11); IMDG Code Class 4 Div. 4.2(12); IMDG Code Class 4 Div. 4.3(13); IMDG Code Class 5 Div. 5.1(14); IMDG Code Class 5 Div. 5.2(15); IMDG Code Class 6 Div. 6.1(16); IMDG Code Class 6 Div. 6.2(17); IMDG Code Class 7(18); IMDG Code Class 8(19); IMDG Code Class 9(20); Harmful Substances in packaged form(21)。
- `categoryOfVessel`（条件抽）：船舶功能或用途分类。
  - 枚举值：general cargo vessel(1); container carrier(2); tanker(3); bulk carrier(4); passenger vessel(5); roll-on roll-off(6); refrigerated cargo vessel(7); fishing vessel(8); service(9); warship(10); towed or pushed composite unit(11); tug and tow(12); light recreational(13); semi-submersible offshore installation(14); jack-up exploration or project installation(15); livestock carrier(16); sport fishing(17)。
- `categoryOfVesselRegistry`（条件抽）：船舶登记地或国籍。
  - 枚举值：domestic(1); foreign(2)。
- `logicalConnectives`（条件抽）：条件逻辑。
  - 枚举值：logical conjunction(1); logical disjunction(2)。
- `thicknessOfIceCapability`（条件抽）：船舶可安全航行的冰厚能力。
- `vesselPerformance`（条件抽）：船舶操纵、主机、设备等性能描述。
- `Information`（条件抽）：无法用专用属性表达的船舶参数。
  - `Headline`：参数标题。
  - `Language`：文本语言。
  - `Text`：参数描述，如"XX吨级"。
  - `fileLocator`：外部文本片段定位。
  - `fileReference`：外部文本文件名。
- `vesselsMeasurements`（条件抽）：船舶测量参数。
  - `comparisonOperator`：比较符，如大于、小于等。
    - 枚举值：greater than(1); greater than or equal to(2); less than(3); less than or equal to(4); equal to(5); not equal to(6)。
  - `vesselsCharacteristics`：船舶特征，如船长、船宽、吃水、总吨。
    - 枚举值：length overall(1); length at waterline(2); breadth(3); draught(4); height(5); displacement tonnage(6); displacement tonnage, light(7); displacement tonnage, loaded(8); deadweight tonnage(9); gross tonnage(10); net tonnage(11); Panama Canal/Universal Measurement System net tonnage(12); Suez Canal net tonnage(13); Suez Canal gross tonnage(14)。
  - `vesselsCharacteristicsValue`：参数值。
  - `vesselsCharacteristicsUnit`：参数单位。
    - 枚举值：metre(1); foot(2); metric ton(3); ton(4); short ton(5); gross ton(6); net ton(7); Panama Canal/Universal Measurement System net tonnage(8); Suez Canal Net Tonnage(9); none(10); cubic metres(11); Suez Canal Gross Tonnage(12)。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`。
- 说明：`FeatureName.displayName` 中英文均不选。

### ContactDetails（联系方式）

- 作用：表达机构、VTS、引航等服务联系方式。
- `callName`（条件抽）：电台、雷达站、引航员等的呼叫名称。
- `callSign`（条件抽）：电台呼号。
- `categoryOfCommPref`（慎用/按需）：通信偏好；除无线电通信外一般不填。
  - 枚举值：preferred calling(1); alternate calling(2); preferred working(3); alternate working(4)。
- `communicationChannel`（条件抽）：通信频道，如 `VHF CH16`。
- `contactInstructions`（条件抽）：联系方式和联系时机补充说明。
- `Language`（必抽）：联系所用语言，仅填 `eng` 或 `zho`；中英双语需分别创建两个 ContactDetails。
- `mMSICode`（条件抽）：9 位 MMSI 码。
- `contactAddress`（条件抽）：联系地址。
  - `deliveryPoint`：街道、建筑、邮箱等投递地址。
  - `cityName`：城市名称。
  - `administrativeDivision`：行政区。
  - `countryName`：国家名称；该 key 已修正为 `countryName`。
  - `postalCode`：邮政编码。
- `frequencyPair`（条件抽）：收发频率对。
  - `frequencyShoreStationTransmits`：岸台发射频率。
  - `frequencyShoreStationReceives`：岸台接收频率。
  - `contactInstruction`：使用该频率对的联系说明。
- `Information`（条件抽）：联系方式补充文本。
- `onlineResource`（按需）：在线资源，子字段同公共字段 `TextContent.onlineResource`。
- `Telecommunications`（条件抽）：电信联系方式。
  - `categoryOfCommPref`：通信偏好。
    - 枚举值：preferred calling(1); alternate calling(2); preferred working(3); alternate working(4)。
  - `contactInstructions`：联系说明。
  - `telcomCarrier`：电信服务商或运营商。
  - `telecommunicationIdentifier`：电话号码等电信标识。
  - `telecommunicationService`：电信服务类型。
    - 枚举值：voice(1); facsimile(2); SMS(3); data(4); streamedData(5); telex(6); telegraph(7); email(8)。
  - `scheduleByDayOfWeek`：按星期划分的服务时间。
    - `categoryOfSchedule`：时间安排类型，如开放、关闭。
      - 枚举值：normal operation(1); closure(2); unmanned operation(3)。
    - `timeIntervalsByDayOfWeek`：按星期划分的时间段。
      - 枚举值：dayOfWeek: Sunday(1); dayOfWeek: Monday(2); dayOfWeek: Tuesday(3); dayOfWeek: Wednesday(4); dayOfWeek: Thursday(5); dayOfWeek: Friday(6); dayOfWeek: Saturday(7)。
- `radioCommunications`（条件抽）：无线电联系方式。
  - `categoryOfCommPref`：通信偏好。
    - 枚举值：preferred calling(1); alternate calling(2); preferred working(3); alternate working(4)。
  - `categoryOfMaritimeBroadcast`：海事广播类型。
    - 枚举值：navigational warning(1); meteorological warning(2); ice report(3); SAR information(4); pirate attack warning(5); meteorological forecast(6); pilot service message(7); AIS information(8); LORAN message(9); SATNAV message(10); gale warning(11); storm warning(12); tropical revolving storm warning(13); NAVAREA warning(14); coastal warning(15); local warning(16); low water level warning/negative tidal surge(17); icing warning(18); tsunami broadcast(19)。
  - `categoryOfRadioMethods`：频段和无线电方式分类。
    - 枚举值：Low Frequency (LF) voice traffic(1); Medium Frequency (MF) voice traffic(2); High Frequency (HF) voice traffic(3); Very High Frequency (VHF) voice traffic(4); High Frequency Narrow Band Direct Printing(5); NAVTEX(6); SafetyNET(7); NBDP Telegraphy (Narrow Band Direct Printing Telegraphy)(8); facsimile(9); NAVIP(10); Low Frequency (LF) digital traffic(11); Medium Frequency (MF) digital traffic(12); High Frequency (HF) digital traffic(13); Very High Frequency (VHF) digital traffic(14); Low Frequency (LF) telegraph traffic(15); Medium Frequency (MF) telegraph traffic(16); High Frequency (HF) telegraph traffic(17); Medium Frequency (MF) Digital Selective Call traffic(18); High Frequency (HF) Digital Selective Call traffic(19); Very High Frequency (VHF) Digital Selective Call traffic(20)。
  - `communicationChannel`：频道。
  - `contactInstructions`：联系说明。
  - `frequencyPair`：收发频率对，子字段同 `frequencyPair`。
  - `signalFrequency`：信号频率。
  - `transmissionContent`：播发内容；若已填 `categoryOfMaritimeBroadcast` 则不填。
  - `timeIntervalsByDayOfWeek`：按星期划分的播发时间段。
    - 枚举值：dayOfWeek: Sunday(1); dayOfWeek: Monday(2); dayOfWeek: Tuesday(3); dayOfWeek: Wednesday(4); dayOfWeek: Thursday(5); dayOfWeek: Friday(6); dayOfWeek: Saturday(7)。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`。
- 说明：VTS 内多分区频道不同时，使用 `radioCommunications` 表达各分区频道和对应联系说明。

### ServiceHours（服务时间）

- 作用：表达服务可用时间。
- `scheduleByDayOfWeek`（条件抽）：按星期划分的时间安排。
  - `categoryOfSchedule`：时间安排类型。
    - 枚举值：normal operation(1); closure(2); unmanned operation(3)。
  - `timeIntervalsByDayOfWeek`：星期和时间段。
    - 枚举值：dayOfWeek: Sunday(1); dayOfWeek: Monday(2); dayOfWeek: Tuesday(3); dayOfWeek: Wednesday(4); dayOfWeek: Thursday(5); dayOfWeek: Friday(6); dayOfWeek: Saturday(7)。
- `Information`（条件抽）：无法结构化的服务时间说明。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`。

### NonStandardWorkingDay（非标准工作日）

- 作用：表达节假日或非标准工作日。
- `dateFixed`（条件抽）：每年同一天重复的节日或国家假日。
- `dateVariable`（条件抽）：公历中日期不固定的日子。
- `Information`（条件抽）：补充说明。
- 公共字段：`FixedDateRange`、`FeatureName`、`SourceIndication`。

## 地理要素字段

以下地理要素均需抽取 `Geometry` 和 `FeatureName`；`FixedDateRange`、`SourceIndication`、`TextContent` 按公共字段规则条件抽取。

### RadioCallingInPoint（报告呼叫点）

- 作用：表达报告制或 VTS 的报告呼叫点。
- `communicationChannel`（条件抽）：报告线可用 VHF 频道。
- `callSign`（条件抽）：电台呼号。
- `trafficFlow`（条件抽）：通过参考点的船舶流向。
  - 枚举值：inbound(1); outbound(2); one-way(3); two-way(4)。
- `orientationValue`（条件抽）：呼叫点方位值。
- `Status`（条件抽）：状态，JSON 未给出枚举，按 S-127 定义填写。
  - 枚举值：permanent(1); occasional(2); recommended(3); not in use(4); periodic/intermittent(5); reserved(6); temporary(7); private(8); mandatory(9); illuminated(12); public(14); synchronized(15); watched(16); un-watched(17); existence doubtful(18); buoyed(28)。
- `componentOf`（条件抽）：所属服务区，如 SRSA。
- `categoryOfCargo`（按需）：货物类型。
  - 枚举值：bulk(1); container(2); general(3); liquid(4); passenger(5); livestock(6); dangerous or hazardous(7); heavy lift(8); ballast(9)。
- `categoryOfVessel`（按需）：船舶类型。
  - 枚举值：general cargo vessel(1); container carrier(2); tanker(3); bulk carrier(4); passenger vessel(5); roll-on roll-off(6); refrigerated cargo vessel(7); fishing vessel(8); service(9); warship(10); towed or pushed composite unit(11); tug and tow(12); light recreational(13); semi-submersible offshore installation(14); jack-up exploration or project installation(15); livestock carrier(16); sport fishing(17)。

### ShipReportingServiceArea（船舶报告服务区）

- 作用：表达船舶报告制服务范围。
- `serviceAccessProcedure`（条件抽）：接入服务的程序。
- `requirementsForMaintenanceOfListeningWatch`（条件抽）：连续守听要求。

### WaterwayArea（水道区域）

- 作用：表达水道、禁止会遇区域、桥区水域等。
- `siltationRate`（条件抽）：水深下降速率描述。
- `Status`（条件抽）：状态。
  - 枚举值：permanent(1); occasional(2); recommended(3); not in use(4); periodic/intermittent(5); reserved(6); temporary(7); private(8); mandatory(9); illuminated(12); public(14); synchronized(15); watched(16); un-watched(17); existence doubtful(18); buoyed(28)。
- `dynamicResource`（条件抽）：动态资源类型。
  - 枚举值：static(1); mandatory external dynamic(2); optional external dynamic(3); onboard dynamic(4)。

### VesselTrafficServiceArea（VTS 服务区）

- 作用：表达 VTS 服务范围和类型。
- `categoryOfVesselTrafficService`（条件抽）：VTS 服务类型。
  - 枚举值：Information Service(1); Traffic Organisation Service(2); Navigational Assistance Service(3)。
- `serviceAccessProcedure`（条件抽）：接入服务程序。
- `requirementsForMaintenanceOfListeningWatch`（条件抽）：连续守听要求。
- 说明：JSON 中此要素的几何字段已统一为 `Geometry`。

### RouteingMeasure（定线制/航路）

- 作用：表达定线制、公共航路、渔船推荐航路。
- `categoryOfRouteingMeasure`（必抽/条件抽）：航路类型。
  - 枚举值：archipelagic sea lane(1); deep water route(2); fairway system(3); recommended route(4); traffic separation scheme(5); two-way route(6)。
- `categoryOfTrafficSeparationScheme`（条件抽）：分道通航制类型。
  - 枚举值：IMO - Adopted(1); not IMO - adopted(2)。
- `categoryOfNavigationLine`（条件抽）：导航线分类。
  - 枚举值：clearing line(1); transit line(2); leading line bearing a recommended track(3)。

### CautionArea（警戒区）

- 作用：表达警戒区。
- `Condition`（条件抽）：警戒区条件。
