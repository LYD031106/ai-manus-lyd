# 通用编码规则（基类属性）

对应《S-127数据生产与发布操作指南（修订版）》第 4 章、5.1 节。
所有要素类都继承这些属性，规则只在这里写一遍。

---

## 1. language 语言

- S-127 数据集**默认语言为英文**。所有非枚举类属性约定**先英文、后中文**，中英内容保持一致。
- 复合属性中的 `language` 子属性填 **ISO 639-3**：英文 `eng`，中文 `zho`。
- **例外 —— ContactDetails**：其简单属性 `language` 表达「联系该机构时使用的语言」，
  只填一种。该要素的所有非枚举属性只用这一种语言填写。
  机构支持中英双语服务时，**分别创建两个 ContactDetails**（一个 eng、一个 zho）。
- 属性不具备多重性时（如 `contactInstructions`），中英双语填进同一格。

### 在要素清单 JSON 里怎么写

| 情形 | 写法 | 生成结果 |
|---|---|---|
| 单值文本属性 | `"source": ["Notice No.4/2021", "2021年第4号通告"]` | 一个元素，英文 + CR + 中文 |
| 名称 | `"featureName": {"eng": "...", "zho": "..."}` | 两个 `featureName` 元素 |
| 文本内容 | `"text": {"eng": "...", "zho": "..."}` | 两个 `information` 元素 |
| ContactDetails | `"attributes": {"language": "eng"}` + 属性只写英文 | 单语要素 |

脚本会把 CR 正确转义成 `&#13;`（真实数据集就是这样分隔双语的）。

## 2. fixedDateRange 数据有效时间

`dateStart` = 生效时间，`dateEnd` = 失效时间。**未提供则不填**。

| 原文 | dateStart | dateEnd |
|---|---|---|
| 自2024年4月7日起执行，有效期至2029年4月6日 | 2024-04-07 | 2029-04-06 |
| 自2010年7月1日起施行 | 2010-07-01 | （不填） |
| 自2024年9月7日起施行，有效期五年 | 2024-09-07 | 2029-09-06 |

「有效期 N 年」= 起始日 + N 年 − 1 天。JSON 里用 `YYYY-MM-DD`，脚本负责包 `<s100:date>`。

## 3. featureName 要素名称

### 专属 vs 可复用

| | sourceIndication | 典型要素 |
|---|---|---|
| **专属要素** | 必填 | 所有地理要素、Regulations、Restrictions、ShipReport |
| **可复用要素** | 不填（便于不同来源要素重复关联） | Authority、ContactDetails、ServiceHours、Applicability、NonStandardWorkingDay |

例外：ContactDetails 的信息来自多份文件时，允许填多个 `sourceIndication`。

### displayName 约定

| 要素 | 英文 featureName | 中文 featureName |
|---|---|---|
| APPLIC（Applicability） | 不选 | 不选 |
| 其他所有要素 | 不选 | **必选 `true`** |

> 语料里存在偏差（个别 Authority 未填、个别 RouteingMeasure 英文填了 true），
> **以指南规则为准**，脚本按指南规则生成。
> 复合属性里的 `featureName`（如 `sourceIndication/featureName`）`displayName` 一律留空。

### 命名要求

- 词首大写；命名尽量精简，重点体现**所属区域/系统 + 功能**
- 英文名称含数值用千分位：`Chinese-flagged Ships of 2,000 GT and Above`
- 能按原文命名就按原文：`曹妃甸东部水域商渔船碰撞高风险警示区`

命名样例（摘自指南 4.3）：

| 要素类 | 名称 |
|---|---|
| WaterwayArea | 厦门刘五店港区；猴屿西航段；厦门港深水航路及其边界外2海里水域 |
| ShipReportingServiceArea | 琼州海峡船舶报告制服务区 |
| RouteingMeasure | 厦门港深水航路 |
| RadioCallingInPoint | 湄洲湾口南报告线；厦门水域船舶报告制东南报告线 |
| Applicability | 琼州海峡重点船舶 |
| Regulations | 琼州海峡中水道安全提示；进出后石港区航行规则 |
| ShipReport | 珠江口报告制航行计划报告／最终报告／变化报告 |

### APPLIC 命名的去重与概括（指南 6.1）

适用船舶列表转 APPLIC 时要**去重、概括，覆盖范围更广的类别优先**。

原文：
```
1. 外国籍船舶
2. 下列中国籍船舶：客船；危险品船舶；操纵能力受到限制的船舶；300总吨及以上的其他中国籍船舶。
```
→ 建 5 个 APPLIC：外国籍船舶、客船、危险品船舶、操纵能力受到限制的船舶、**300总吨及以上的船舶**。
「外国籍船舶」已是更广类别，第 2 点的细分类别**无需再标国籍属性**。

另一例：`(5) 1000总吨及以上其他国内航行船舶` → APPLIC 名为「1000总吨及以上国内航行船舶」。

## 4. sourceIndication 资料来源

地理要素 0 或 1 个；信息要素 0 或多个。

| 子属性 | 填法 |
|---|---|
| `categoryOfAuthority` | 发文机构类型；直属海事局及以上 → `maritime` |
| `countryName` | `China` |
| `reportedDate` | 文件来源日期，优先级：**印发时间 > 签发时间 > 网络发布时间** |
| `source` | **优先填文件编号**，中英文同时填；无编号才填文件名称 |
| `sourceType` | 直属海事局及更高级别 → `law or regulation`；地方海事局及同级、航行通告、ENC → `official publication` |
| `featureName` | 发文机构/组织名称，`displayName` 留空，`language` 必填且唯一 |

`source` 写法：`["Notice No.4/2021", "2021年第4号通告"]`，机构名进 `featureName`。

- 文号可能登记在《现行有效规范性文件目录》里，**要去查**，优先用文号。
- 只能用文件名时，删掉「XX海事局关于发布」「的通告」等字样，
  例：只保留「中华人民共和国福建海事局VTS服务指南」。
- 英文机构名可用海事常见缩略词：`CHINA MSA`、`FUJIAN MSA`、`VTS Center`。

**多来源**：唯一的 `sourceIndication` 填「描述该要素地理位置」的那份文件；
其他来源填进 `textContent` 的 `sourceIndication`。

### 地理要素来源的特殊情形（指南 5.1）

以下三种情况，`sourceIndication` **仍然填资料文件**（不是填 ENC）：

1. 文件只给了专有名称、没给几何范围，几何取自 ENC 对应要素
2. 几何由文件描述 + ENC 要素共同构建，或依据示意图勾绘
3. 几何由编辑人员理解勾绘

## 5. textContent 文本内容

- `categoryOfText`：`text` 有内容时**必选**。XSD 只有三个取值：
  `extract`（摘录，最常用）/ `abstract or summary`（摘要）/ `full text`（全文）。
  > 指南 4.5 的行文容易被读成还有个 `information` 取值 —— 那其实是指
  > **子元素** `information`，不是 `categoryOfText` 的枚举值。语料里也只出现
  > `extract` 与 `abstract or summary`。
- `information/text` 用于表达**无法通过枚举属性表达、但对合规航行有重大意义**的内容。
- **仅适用单一地理要素的条文填进该要素的 `textContent`，尽量少建信息要素。**
- **条文中描述范围的文字，若已转成几何，`text` 里不再重复。**

案例：
> 「第二百零七条 船舶航经4号灯塔至14号灯桩之间水道时，航速不得超过20节，不得低于3节。」

→ 建 `RestrictedAreaNavigational`（`restriction = speed restricted`），
`information/text` 只填「航速不得超过20节，不得低于3节。」（不含范围描述、不含条款号）。

### 长度

S-127 规定 `text` 上限 **300 字符（UTF-8）**。超长时用多个 `information` 拆分表达。
真实数据集中长条文用 CR 分行后每行都在限内 —— 校验脚本按此判定：
单行超 300 判 ERROR，仅总长超 300 判 WARN。

### 条款序号

`text` 中**不标示**原文的条款、段落序号（第X条、X.X.X）。
但《S-127要素生产与检查记录表》必须记录条款来源以便溯源
—— 在要素清单里用 `"clause": "附件1 二（三）"` 记录，它只进记录表、不进 GML。

## 6. 英译（指南 6.6）

1. 官方发文无英文版时，先**网络搜索英文关键词**，找权威机构的相关英文发文用于参考引用。
   例：《珠江口水上交通安全特别监管区管理规定》→ 搜 `safety + water traffic + pearl river`。
2. 用工具英译后**逐句核对**，尽量使用海事、航海专业英语。
3. 中文括号「（）」在英文文本中转成英文括号 `()`。
4. 从 PDF 复制原文会带入多余空格、半拼字符，要清理（指南 6.7）。
