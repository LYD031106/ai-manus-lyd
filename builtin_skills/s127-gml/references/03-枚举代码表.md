# 枚举代码表
由 `scripts/gen_s127_catalogue.py` 从 **S127FC.xml**（要素目录，v1.0.1-20190628）生成，
共 51 个枚举属性、452 个取值。
要素目录换版就重跑生成脚本，不要手改。

**填法**：要素清单里写 label（英文原文），`build_gml.py` 自动补 `code`。
写错 label 会被 `validate_featureset.py` 判 ERROR，并列出该属性的全部合法取值。

## code 是怎么来的

S127.xsd 的 `xs:enumeration` 只给 label，不给数值。真实 GML 里却是
`<restriction code="27">speed restricted</restriction>` —— **数值来自要素目录
S127FC.xml，每个取值自带官方 `code`**，本表直接照抄，不做推算。

⚠️ **不要按序号推断 code**：431 个取值里有 **46 个**官方 code 与其在列表中的
1-based 序号不等（如 `categoryOfMilitaryPracticeArea` 整体偏移 1）。按位置推算必错。
经 13 个生产数据集 **882 处** `code="N"` 实测，目录官方值吻合 882/882。随时可复核：

```bash
python scripts/gen_s127_catalogue.py --verify '示例/**/*.gml'
```

> 要素目录增删过取值后 code 可能变动。换要素目录版本后，
> **先跑一次上面的复核命令**再投产。
